# CST Agent 简化说明

当前仍是Pi Agent＋PiDeck＋现有CST MCP，没有另换框架。你已基本认可上轮工程检查；本轮继续完善工作台，数值结果和全部功能尚未因此验收。

## 现在怎样使用

1. 在独立CST版PiDeck选择对应的W3验收会话，确认中央显示的完整工程路径。
2. 点“重新读取工程”，查看3D、原理图、参数与任务。此动作重开已保存工程并读回，不求解。
3. 在3D图或对象列表选实体，查看材料/包围盒；可隐藏或调整透明度。“隐藏外壳，检查线缆”显示实际Harness路由中心线，不是求解网格。
4. 在原理图选RES1/RES2，按实际单位改负载；在参数页改L/r等已有参数。每次有意义的修改另存新版本，旧版本保留。
5. 用自然语言让Pi读回刚改的值，再改另一个值。默认“跟随当前工程”自动显示后台新版本；手动选历史版本则保留该选择，点跟随按钮回到当前版本。
6. 保存、释放连接、重新读取，核对数值仍一致。点“打开会话文件夹”或“定位.cst文件”查看完整原生工程。

未连接后台的历史版本先重新读取才能编辑。原生CST外部保存改变文件后，旧状态写入会被拒绝；需要重新读取。重新读取拒绝正在运行或状态未知的求解以及后台未保存修改。

## 本轮支持哪些修改

| 内容 | 当前范围 |
|---|---|
| 3D | 选择、属性查看、隐藏、透明；几何尺寸经已有设计参数编辑 |
| 原理图 | 实际元件/探针/地/引脚与Net；电阻值及原生双精度端接属性，单位逐项核对 |
| 设置 | 频段min/max、已有瞬态task的tmax；只设置和读回，不执行Update |
| 激励与求解器 | 当前方向、极化、用户信号标识、端口、探针、任务与求解器字段；高级编辑未接入 |
| 网格 | 尚无可显示的真实网格几何；仅列已有统计，明确不作为网格图 |
| 结果 | 显式读取已有原生结果并保留来源；manual是用户声明，不能据时间戳推断 |

原生结果变化时，旧曲线会失效；不把STL线框、网格数量、旧曲线或同路径缓存当作新结果。

## 两个案例的口径

222交互回归使用独立变体：界面RES1=75Ω，实际Pi读回后将RES2改为60Ω，接线不变；新版本已保存并在工作台显示，重开核对一致。原先已基本认可的50Ω/50Ω检查副本继续保留。没有新增222完整V/I。

偶极子使用独立官方参考副本：界面L80→82，Pi实际读回后将r改为1.2，保留L82；工作台显示及保存重开通过。两例均含开发者恢复提示和重试，详细成功/失败顺序见[交付台账](delivery-evidence.md)。

## 文件与记录

每个PiDeck会话绑定一个稳定总目录，标题变化不会换目录；已有CST目录的草稿也能在重启后恢复。内部区分工程版本、真实历史作业、导出和过程记录。Pi JSONL仍在原位置，另归档可读副本。

实际路径集中在本机固定“CST-Agent-阅读入口.md”，不复制另一套总方案。原始工具调用、失败、重试、保存的模型和操作收据可用于论文工程记录；正式对比实验、数值精度和新仿真验收另做。
