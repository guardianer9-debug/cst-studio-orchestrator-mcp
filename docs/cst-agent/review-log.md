## 5. 更新纪律

R1 直接修改主方案并更新版本，同时追加审查记录，不另建一个互相竞争的总方案。对 R0 的反对意见必须保留，不要求 Codex 认可 ChatGPT；ChatGPT 复核也必须引用 R1 的实际提交和证据，不以两方一致代替测试。

每轮使用输入提交 SHA，输出 SHA 放在提交后回执/聊天中，避免自指 hash。设计冻结后重大改变仍走此机制，但只审变更及影响范围。历史失败、不支持和未验证事项保留，不能通过改名或删除测试将其消失。
