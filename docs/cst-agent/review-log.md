### 6.4 关键证据与反例

公开定位汇总见[主方案§18.4](architecture-and-delivery-plan.md#184-r1-本地只读核验登记)，完整材料不上传。

1. `server.run_server()`先connect后开stdio，R0的L1若直接执行会违反无CST测试假设；已要求显式no-connect模式。
2. `schematic_list`已有block/net读取，但不含完整属性/单位；新建工具返回设置参数并不能证明实际值已读回。`SimulationTask.Update`会运行含子任务，不是普通“刷新”。
3. `execute_vba`的AttributeError跨域回退、`is_solver_running`异常返回False、状态MsgBox和结果str都可能掩盖错误。R1要求显式路由、unknown与分域数值读取。
4. E2为真实联合启动后的失败，不能改成通过；E3若干日志是2024随包示例缓存，不能证明当前MCP。E4仅支持FDTD交互复用，不外推CST。
5. 原始官方帮助提供入口，不提供跨线程/连接抢占保证；截图转录提供范围种子，不证明未展开菜单或原图完整性。

### 6.6 推荐首包及预算

首包为[主方案§14.1 CST-1/P1A](architecture-and-delivery-plan.md#141-首批交付范围222耦合与官方算例完整复现)。改造集中在server/config、CSTClient、project/parameters/schematic与注册边界，复用现有生成器/原理图创建器和本地增强，不新增竞争模型真源。

建议2–4个开发工作日；未来批准的L2实机窗口≤30分钟、最多4次专用实例启动，两域各≤3次完整尝试、每次≤5分钟；0次Provider、0次Mesh、0次求解。监控阈值每自有进程树4GiB/整批产物512MiB仅作建议，不宣称硬隔离；启动开销/许可证不满足就停止调整预算。需求解/真实取消则另批P1B（两域总启动≤6、单次≤5分钟、总≤30分钟）。本轮没有消费这些预算。

首包成功至少意味着两域实际读回、保存恢复、拒绝误绑定/过期操作、重试不重复副作用与错误状态诚实；不意味着完整UI、可取消长求解或物理PASS。出现原件可能被改、未知弹窗、身份漂移、状态未知、预算超限或重复失败无新证据即停止，不静默扩大范围。
