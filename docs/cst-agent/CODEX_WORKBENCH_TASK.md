## 5. 以用户可操作的流程验收

在实际CST版PiDeck验证，而不是只测磁盘build或组件：

打开偶极子 → 中央查看模型/相应网格及结果 → 手动改当前参数并读回 → Pi读出新值 → 手动运行 → 查看该次结果 → 让Pi再修改/运行 → 工作区同步 → 保存重开。

还要证明Provider不可用时，手动保存、管理已配置任务、查看工件和停止控制仍可用；切换偶极子和222不会混用任务/曲线；同一路径的新旧运行可区分；导出和切视图不改建模History、不重跑或删除结果。
